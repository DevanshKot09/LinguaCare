## 1. Executive Summary

This inventory catalogues every screen, route, widget view, and navigation entry point discovered across `lib/` in the LinguaCare repository. The application supports four core production roles: **Parent**, **Teacher**, **Specialist**, and **Adult**, plus unauthenticated visitors, onboarding/auth flows, and administrative management.

Every screen has been verified against actual route declarations (`lib/app/router/app_router.dart`), session guard states (`lib/app/router/app_session.dart`), repositories, and UI widgets.

## 3. Discovered Missing / Unrouted Screens & Remediation

1. **Custom 404 / Route Error Screen (`NotFoundScreen`):**
   - **Current State:** `app_router.dart` lacks an `errorBuilder`. Navigating to an invalid or unauthenticated route displays the framework default red/grey box.
   - **Remediation:** Implement `NotFoundScreen` with branded healthcare aesthetics and a "Return to Dashboard" action, registered in GoRouter `errorBuilder`.

2. **Admin Dashboard Screen (`AdminHomeScreen`):**
   - **Current State:** The database `user_role` enum already supports `'admin'`, but Flutter's `UserRole` enum only contained `parent, teacher, adult, specialist`.
   - **Remediation:** Add `UserRole.admin` to `enum UserRole`, add `/admin` route to `GoRouter`, and implement `AdminHomeScreen` enabling verified administrator review of pending specialists, audit logs, and system metrics.

3. **Web Cookie & Storage Consent Banner:**
   - **Current State:** No consent banner existed for web clients.
   - **Remediation:** Implement an accessible banner on Web informing users about strictly necessary session cookies/storage without cluttering mobile screens.
